- 📘 [سند محصول و نقشه راه (Product Blueprint)](docs/product-blueprint.md) — تحلیل کامل: برند، پرسوناها، ساختار سایت، صفحات، مسیر کاربر، امکانات، جستجو و فیلتر، UX/UI، معماری و تکنولوژی، نقشه راه و KPIها.
