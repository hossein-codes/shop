# فونت‌ها

## وزیرمتن (Vazirmatn) — موجود ✅
`Vazirmatn-Variable.woff2` فونت متغیر متن‌باز (مجوز OFL) است که به‌عنوان فالبک همیشه همراه پروژه است. فایل مجوز: `Vazirmatn-OFL.txt`.

## ایران‌سنس (IRANSans) — نیازمند نصب دستی 📦
فونت اصلی برند طبق Design System v1.1 (بخش ۳.۱) **ایران‌سنس** است که تجاری است و فایل آن نمی‌تواند در گیت باشد:

1. لایسنس وب را از [fontiran.com](https://fontiran.com) خریداری کنید.
2. نسخه‌ی متغیر (IRANSansX Variable) را به فرمت woff2 دریافت کنید.
3. با این نام دقیق در همین پوشه قرار دهید:
   ```
   public/fonts/IRANSansX.woff2
   ```
4. هیچ کار دیگری لازم نیست — `@font-face` در `src/app/globals.css` این فایل را با اولویت بالاتر از وزیرمتن لود می‌کند (`font-display: swap`).

> تا زمانی که فایل ایران‌سنس قرار نگیرد، سایت به‌صورت خودکار با وزیرمتن (هم‌خانواده‌ی سبک ایران‌سنس) رندر می‌شود و چیزی خراب نمی‌شود.

فایل‌های `IRANSans*.woff2` در `.gitignore` مسدود شده‌اند تا تصادفاً commit نشوند.
