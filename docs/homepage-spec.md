## مشخصات تک‌تک بخش‌ها

### S1 — هیرو کمپین (اسلایدر) · P0
| | |
|---|---|
| **هدف** | قوی‌ترین پیشنهاد لحظه را در ۳ ثانیه اول برساناند |
| **محتوا** | ۲–۳ اسلاید، هر اسلاید: تصویر تمام‌عرض (دسکتاپ 21:9، موبایل 4:5 با برش هوشمند) + تیتر حداکثر ۴ کلمه + حداکثر یک خط توضیح + دکته CTA |
| **متن نمونه** | تیتر «کالکشن پاییزِ روشن» · CTA «خرید کالکشن» — یا «تا ٪۴۰ پایان فصل» · CTA «دیدن تخفیف‌ها» |
| **رفتار** | اتوپلی ۶ ثانیه (توقف در hover و برای reduced-motion) · فلش دسکتاپ · swipe موبایل · نقاط شمارش · preload اسلاید اول (LCP) |
| **لینک** | هر اسلاید → کالکشن/دسته/کمپین. **اسلاید بدون لینک خرید = حذف** |
| **نیست** | اسلایدر ۸تایی نمایشی، «به فروشگاه ما خوش آمدید»، دکمه «بیشتر بدانید» |
| **داده** | `slides[]: {image, imageMobile, title, subtitle?, ctaText, href}` |

## سربرگ بخش‌ها (استاندارد یکسان)

```
[عنوان کوتاه تجاری ≤۴ کلمه]          [مشاهده همه ←]
────────────────────────────────────────────
```
عنوان h2 (۲۴–۲۷px بولد) · لینک «مشاهده همه» با آیکون فلش · فاصله عمودی بین بخش‌ها: موبایل ۵۶ / دسکتاپ ۹۶.

## قوانین صفحه (ضد سایت‌شخصی)

1. هر بخش یکی از این ۴ دسته است: **محصول / دسته / کمپین / اعتماد** — خارج از این‌ها ممنوع.
2. هیچ بخشی بدون CTA یا لینک خرید ساخته نمی‌شود.
3. تیترها تجاری و کوتاه: «جدیدترین‌ها»، «تا ٪۴۰»، «پرفروش‌های هفته» — نه شعار ادبی.
4. همه بخش‌ها داده‌محور (props→API) + Skeleton + حالت خالی تعریف‌شده.
5. S8/S9 فقط با محتوای واقعی می‌آیند؛ در غیر این صورت صفحه بدون آن‌ها کامل و تمیز است.

## ترتیب ساخت پیشنهادی

**بسته اول (P0):** S1 هیرو → S2 شورتکات → S3 جدیدترین‌ها → S5 پرفروش‌ها → S4 بنرها → صفحه از اینجا «کامل تجاری» است
**بسته دوم (P1):** S6 فروش ویژه → S7 کالکشن → S10 سئو
**بسته سوم (با محتوا):** S8 مجله · S9 UGC
