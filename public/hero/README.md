# تصاویر هیرو

سه تصویر اسلایدر هیرو اینجا هستند و در `src/data/demo.ts` (بخش `demoHeroSlides`) به همین مسیرها وصل‌اند:

```
public/hero/hero-1.png  → اسلاید ۱ (کالکشن پاییزِ روشن → /collections/light-fall)
public/hero/hero-2.png  → اسلاید ۲ (فروش ویژه پایان فصل → /sale)
public/hero/hero-3.png  → اسلاید ۳ (مردانه → /c/men)
```

**جایگزینی با تصاویر اصلی:** فقط فایل‌ها را با همین نام‌ها بازنویسی کنید — هیچ تغییری در کد لازم نیست.
ترجیحاً تصویر عریض (نسبت ~۲.۴ به ۱ یا بازتر) با متن داخل خود تصویر؛ در غیر این صورت `object-cover` از بالا/پایین برش می‌زند.

**تنظیم ارتفاع هیرو:** فایل `src/components/layout/../../components/home/hero-slider.tsx` → ثابت‌های `HERO_ASPECT_DESKTOP` و `HERO_ASPECT_MOBILE` (با کامنت ⬅️ مشخص شده‌اند) — عدد دوم نسبت، ارتفاع است؛ بزرگ‌تر = کوتاه‌تر.

فایل‌های فعلی placeholder هستند (تا رسیدن تصاویر نهایی کارفرما).
